# Tkinter Calculator 🧮

A simple GUI-based calculator built with Python and Tkinter. This project was created as a beginner-friendly practice project to learn GUI development, button events, functions, and basic arithmetic operations.

## Features

- **Number Buttons:** Enter numbers from 0 to 9.
- **Addition:** Add two numbers.
- **Subtraction:** Subtract one number from another.
- **Multiplication:** Multiply two numbers.
- **Division:** Divide one number by another.
- **Clear Button:** Clear the current input.
- **Quit Button:** Close the calculator window.
- **Division by Zero Check:** Displays an error message when attempting to divide by zero.

## Technologies Used

## Requirements

- Python 3
- Tkinter

Tkinter is included with many Python installations. If it is unavailable in your environment, install or configure the appropriate Tk support for your Python installation.

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the following command:

   ```bash
   python calculator.py
   ```

   Depending on your system, you may need to use `01. Calculator.py` instead.

4. The calculator window will open.
5. Enter the first number, select an arithmetic operator, enter the second number, and click `=`.
6. Use the Clear button to clear the input or the Quit button to close the application.

## Current Limitations

- Supports integer input only.
- Does not support decimal input.
- Does not support keyboard-based calculator input.
- Does not maintain calculation history.
- Input validation and error handling can be improved.
- Chained calculations are not supported.
